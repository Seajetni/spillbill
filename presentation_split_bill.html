01. The Problem

ทำไมการหารเงินกับเพื่อนถึงเป็น "เรื่องยาก"?

ปัญหาคลาสสิกของคนออกเงินก่อน ที่เจอกันแทบทุกโต๊ะอาหารและทุกทริป

🤦‍♂️

ทวงยาก กระอักกระอ่วนใจ

ไม่กล้าทวง กลัวเสียมารยาทหรือดูเป็นคนงก เพื่อนบางคนไม่ได้ตั้งใจเบี้ยว แต่ "ลืมโอน" พอไม่ทวงก็กลายเป็นหนี้สูญ

📑

คำนวณซับซ้อน ปวดหัว

บางคนกินเนื้อ บางคนไม่กินแอลกอฮอล์ แถมยังมี Service Charge 10% และ VAT 7% พร้อมเศษสตางค์ที่ไม่ลงตัว

🏦

ขั้นตอนโอนยุ่งยาก

ต้องส่งเลขบัญชี สลับแอปไปกรอกยอดเงิน แคปสลิปส่งเข้าแชท พอคนเยอะ สลิปปนกันจนตรวจยอดไม่ถูก

02. The Solution

SplitBill: ทุกคำตอบในแอปเดียว

ออกแบบฟังก์ชันตั้งแต่การเริ่มเปิดบิล จนถึงเพื่อนสแกนจ่ายเงินครบ 100%

📝

สร้างบิลยืดหยุ่น

สร้างบิลว่าง กรอกเอง หรือทำซ้ำจากบิลเดิม ไม่จำกัดจำนวนคนในกลุ่ม

⚖️

หารได้ 2 รูปแบบ

เลือกได้ทั้งหารเท่ากัน (Equally) หรือหารตามเมนูจริงที่กิน (By Item)

🤖

AI Voice Nudge

สร้างเสียงทวงหนี้ AI หลากบุคลิก ส่งเป็นไฟล์เสียงหรือลิงก์เข้า LINE

📱

เพื่อนไม่ต้องลงแอป

เพื่อนเปิดลิงก์เว็บ ฟังเสียง สแกน QR หรือกดเปิดแอปธนาคารจ่ายได้ทันที

🎯 ผลลัพธ์ที่ได้: เพื่อนโอนไวขึ้น 3 เท่า เจ้าหนี้ไม่เครียด ความสัมพันธ์ในกลุ่มยังแฮปปี้!
🎉
03. Core Feature: Math Engine

ระบบคำนวณบิลและเศษสตางค์อัจฉริยะ

แก้ปัญหาเศษสตางค์ไม่ลงตัวด้วย 3 กลยุทธ์ตามมาตรฐานการเงิน

1. คนสำรองจ่ายรับผิดชอบเศษ (Payer Absorbs)

คนจ่ายหลักรับเศษไป เพื่อนจ่ายเป็นจำนวนถ้วน เช่น 33.33 บาท

2. กระจายเศษสตางค์ (Distribute Evenly)

แจกเศษ 1 สตางค์ให้คนแรก ๆ ในลิสต์ เพื่อให้ยอดรวมตรงเป๊ะ 100%

3. ปัดเป็นจำนวนเต็มบาท (Round to Baht)

ปัดเศษขึ้นเป็นจำนวนเต็ม สะดวกสบายไม่ต้องโอนเศษสตางค์

🧮 ทดลองคำนวณบิลจริง

ยอดเฉลี่ยต่อคน
333.33 ฿
ยอดสุทธิ 1,000.00 บาท หาร 3 คน
04. Core Feature: Payments

เชื่อมต่อ PromptPay และแอปธนาคารไทย

จ่ายเงินได้ทันทีใน 10 วินาที ผ่าน Deep Link และ Dynamic QR Code

📲

PromptPay QR จริง

สร้าง QR Code มาตรฐาน EMVCo ผูกเบอร์หรือเลขบัตรประชาชนของเจ้าหนี้จริง พร้อมระบุยอดเงินตรงเป๊ะ

🔗

Deep Link ธนาคาร

แตะครั้งเดียวเปิดแอปธนาคารในเครื่องเพื่อนทันที รองรับทั้ง SCB Easy, K PLUS, ttb touch, KMA

🧾

บันทึกรูป & แนบสลิป

เซฟรูป QR ลง Photo Library อัตโนมัติ พร้อมระบบให้อัปโหลดภาพสลิปตรวจสอบความถูกต้อง

🟢 K PLUS
🟣 SCB Easy
🔵 ttb touch
🟡 KMA Krungsri

09. Deployment: Windows App

ความพร้อมของแอปพลิเคชันเวอร์ชัน Windows

คอมไพล์เป็นโปรแกรมเดสก์ท็อป Standalone รันลื่นไหลบน Windows 10 & 11 (64-bit)

🪟

split_bill.exe

● Release x64 Binary
  • คอมไพล์ด้วย Visual Studio C++ Compiler
  • รองรับทั้งจอกว้าง จอสัมผัส และคีย์บอร์ดชอร์ตคัต
  • เชื่อมต่อ Native Audio API เล่นเสียงและอัดเสียงสมบูรณ์
  • ทำงานแบบ Standalone ไม่ต้องติดตั้ง Flutter บนเครื่องปลายทาง
⚡ 1-Click Standalone Installer: 11.4 MB (Single EXE)
⬇️ ดาวน์โหลดตัวติดตั้ง SplitBill_Setup.exe (1-Click)
✨ จุดเด่น 1-Click EXE:
• ดับเบิ้ลคลิกไฟล์เดียว ติดตั้งและเปิดแอปทันทีใน 1-2 วินาที
• สร้างชอร์ตคัตบน Desktop และ Start Menu อัตโนมัติ
• ไม่ต้องต่อเน็ต และไม่ต้องใช้สิทธิ์ Administrator (UAC)
✅ ที่อยู่ไฟล์พร้อมใช้งาน: D:\code\split_bill\SplitBill_Setup.exe
